# CloudCart

## Cloud-Native E-Commerce Microservices Platform

CloudCart is a production-oriented e-commerce microservices platform
built to demonstrate AWS infrastructure automation, Kubernetes,
GitOps, and DevSecOps practices.

## Technology Stack

- AWS
- Terraform
- Amazon EKS
- Docker
- Kubernetes
- Helm
- ArgoCD
- GitHub Actions
- DevSecOps security scanning
